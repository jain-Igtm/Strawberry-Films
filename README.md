# Strawberry Films

Programmatic 3D animated stories, rendered without hand animation.

## First production: *Arthur: Lab Break*

The repository currently builds a thirty-second silent Blender short in which Arthur changes into a severe psychopathic dissociative state inside a laboratory. His hair rises, loose equipment lifts around him, and two guards attempt to contain him.

The scene, characters, materials, animation, lighting, effects, and cameras are generated by Python. GitHub Actions builds the `.blend` file, renders the animation in parallel frame ranges, and assembles the frames into an H.264 MP4.

### Render from GitHub

1. Open **Actions**.
2. Select **Render Arthur Lab Short**.
3. Choose **Run workflow**.
4. When the workflow finishes, download the `arthur-lab-short` artifact.

The artifact contains:

- `arthur-lab-short-silent.mp4`
- `arthur-lab.blend`

### Render locally

```bash
mkdir -p build render/frames output
blender --background --python scripts/arthur_lab_short.py -- \
  --build "$PWD/build/arthur-lab.blend"
blender --background build/arthur-lab.blend \
  -o "$PWD/render/frames/frame_####" -F PNG -a
ffmpeg -framerate 15 -start_number 1 \
  -i render/frames/frame_%04d.png \
  -c:v libx264 -crf 18 -pix_fmt yuv420p \
  output/arthur-lab-short-silent.mp4
```
